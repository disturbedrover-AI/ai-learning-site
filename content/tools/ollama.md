Ollama handles the fiddly parts of running a model: downloading the right file,
picking settings for your hardware, and serving it locally. You type
`ollama run llama3.2` and start chatting. Recent versions include a simple chat
app, and many other tools (such as Open WebUI) can use Ollama as their engine.
