# AI Learning Site

A calm, themeable website for learning about AI. Built with Next.js, Tailwind CSS,
Framer Motion and next-themes.

## Run it locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Adding content

Add a file to the right folder in `content/`. See `content/README.md` for the
fields each kind of file needs.

## Adding a theme

Add a block to `app/themes.css` and one line to `lib/themes.ts`.

See `CLAUDE.md` for the full project guide and rules.
